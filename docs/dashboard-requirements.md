
# Dashboard Requirements

## Project Name
TaskFlow

## Feature Name
Project Dashboard

## Objective
To provide an overview of projects and tasks.

## Functional Requirements
1. Display total projects.
2. Display total tasks.
3. Display pending tasks.
4. Display completed tasks.
5. Display recent projects.
6. Display task status.

## Non-Functional Requirements
1. Dashboard should load quickly.
2. Interface should be user-friendly.
3. Data should be accurate.
4. Dashboard should be responsive.
