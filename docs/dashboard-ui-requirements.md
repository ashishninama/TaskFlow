# TaskFlow - Dashboard UI Requirements

## 1. Dashboard Purpose
The purpose of the TaskFlow Dashboard is to provide users with a
centralized view of their projects and tasks.
Users can quickly check project details, task progress, pending tasks,
completed tasks, and recent projects from one place.

## 2. Dashboard Layout
The TaskFlow Dashboard will have a simple and user-friendly layout.

1. A sidebar on the left side for navigation.
2. A header at the top of the dashboard.
3. A main content area to display project and task information.
4. A user profile section to display user details.

The layout should be clean, organized, and responsive.


## 3. Sidebar Menu
The sidebar will provide navigation options to access different
sections of the TaskFlow application.

The sidebar will contain the following menu items:

1. Dashboard
2. My Projects
3. My Tasks
4. Reports
5. Settings
6. Logout

The sidebar should be simple and easy to navigate.
## 4. Dashboard Header
The dashboard header will be displayed at the top of the page.

It will contain the following elements:

1. Dashboard title.
2. Search bar to search projects and tasks.
3. Notification icon.
4. User profile shortcut.

The header should be clean and easy to use.
## 5. Main Content
The main content area will display important project and task information.

It will contain the following sections:

1. Total Projects – Displays the total number of projects.
2. Total Tasks – Displays the total number of tasks.
3. Pending Tasks – Displays the number of pending tasks.
4. Completed Tasks – Displays the number of completed tasks.
5. Recent Projects – Displays a list of recently created or updated projects.
6. Task Status Overview – Displays task progress and status.

The main content should be organized and easy to understand.
## 6. User Profile Section
The user profile section will display basic information about the logged-in user.

It will contain the following details:

1. User name.
2. User profile picture.
3. User email address.
4. Account settings option.
5. Logout option.

Users should be able to access their account information easily.
## 7. Acceptance Criteria
The TaskFlow Dashboard will be accepted when the following conditions are met:

1. The dashboard displays a clear and user-friendly layout.
2. The sidebar contains all required navigation menu items.
3. The header displays the dashboard title, search bar, notification icon, and user profile shortcut.
4. The main content displays project and task statistics.
5. Recent projects are displayed correctly.
6. The user profile section displays user information.
7. The dashboard is responsive on desktop, tablet, and mobile devices.
8. All dashboard sections are easy to navigate and understand.
