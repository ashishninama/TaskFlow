
# TaskFlow - User Stories

## US-001: View Total Projects

As a project manager,
I want to see total projects,
So that I can track all projects.

Acceptance Criteria:
- Total project count should be visible.
- Count should show actual database data.
- If no projects exist, show 0.

## US-002: View Total Tasks

As a developer,
I want to see total tasks,
So that I can track my workload.

Acceptance Criteria:
- Total tasks should be visible.
- Count should be accurate.
- Count should update when tasks change.

## US-003: View Completed Tasks

As a project manager,
I want to see completed tasks,
So that I can monitor project progress.

Acceptance Criteria:
- Completed task count should be visible.
- Only completed tasks should be counted.

## US-004: View Pending Tasks

As a developer,
I want to see pending tasks,
So that I know which tasks remain.

Acceptance Criteria:
- Pending tasks should be visible.
- Only pending tasks should be counted.
