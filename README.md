
# TaskFlow - Project Management System

## 1. Project Overview
TaskFlow is a web-based project management application.
It helps teams manage projects, tasks, deadlines and bugs.

## 2. Project Objectives
- Manage multiple projects.
- Create and assign tasks.
- Track task progress.
- Manage deadlines.
- Report and track bugs.

## 3. Technology Stack
- Frontend: React
- Backend: Python, FastAPI
- Database: PostgreSQL
- Version Control: Git and GitHub
- Testing: Pytest

## 4. Project Structure
- backend/
- frontend/
- docs/
- tests/

## 5. Project Status
Currently in the planning and setup phase.
